PROYECTO: Regresión polinomial en Python

Archivos:
- regresion_polinomial_metricas.ipynb
- datos_regresion_polinomial.csv

Dependencias:
pip install pandas numpy matplotlib seaborn scikit-learn scipy

Ejecución:
jupyter notebook regresion_polinomial_metricas.ipynb

El notebook incluye:
- Regresión polinomial con PolynomialFeatures
- Pipeline de scikit-learn
- Comparación de grados 1, 2 y 3
- R2
- RMSE
- MAE
- Pearson
- Bias
- Gráficos de predicciones y residuos
- Dataset CSV incluido
