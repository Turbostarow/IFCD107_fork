2. ARRAYS MEDIANTE LISTAS usando una clase
------------------------

class GestionArrays:
    """
    """

    def __init__(self, array):
        self.array = array
    def getarray(self):
        return self.array
    def elemento_posicion(self,n):
        longitud = len(self.array)
        if n < longitud -1:
            return self.array[n]
        else:
            return "-1"
    def modificar(self,pos,val):
        self.array[pos]=val
    def addfinal(self,val):
        self.array.append(val)
    def addpos(self,pos,val):
        self.array.insert(pos,val)
    def sumaelementos(self):
        suma = 0
        for i in range(len(self.array)):
            suma += self.array[i]
        return suma

Invoco a la clase
gestarr = GestionArrays([2,3,5,7,9,11])
print(gestarr.elemento_posicion(1))

import numpy as np

(4, 3)

4 muestras
3 variables


Seleccionar una variable:

humedad = X[:, 0]

20. EJEMPLO DE DATOS DE IMÁGENES
--------------------------------

Una imagen en escala de grises puede representarse como una matriz.

imagen = np.array([
    [0,   0,   255],
    [0,   255, 0],
    [255, 0,   0]
])

print(imagen)


Una imagen RGB tiene normalmente tres dimensiones:

alto x ancho x canales


Por ejemplo:

imagen_rgb = np.zeros((100, 200, 3))

print(imagen_rgb.shape)

Resultado:

(100, 200, 3)


Para una colección de 32 imágenes:

imagenes = np.zeros((32, 100, 200, 3))

print(imagenes.shape)


Interpretación:

32 imágenes
100 píxeles de alto
200 píxeles de ancho
3 canales RGB
